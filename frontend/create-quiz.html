📝 Типы вопросов:
• select - выбор одного варианта (answer: число)
• multiselect - выбор нескольких (answer: [2, 3, 5])
• input - текстовый ответ (answer: "строка")
💡 Подсказка (hint):
Массив чисел, которые будут показаны как кнопки для выбора.
Например, если answer: 5, hint: [3, 4, 5, 9] - игроку будут показаны кнопки 3, 4, 5, 9.
